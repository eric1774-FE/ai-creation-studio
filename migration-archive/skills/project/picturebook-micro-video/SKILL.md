# Picturebook Micro Video（绘本微动作视频）

把插画/绘本图片转成缓慢、轻柔的微动作视频。画面保持绘本插画质感，动作幅度小、节奏慢，符合低龄（2–4 岁）绘本的安静调性。

## 何时使用
- 用户给绘本/插画图，要求「让图片动起来」「加微动作」「做成视频」「绘本转视频」。
- 用户只有图片，需要逐页规划微动作并生成视频。

## 工作流

### 1. 读取输入与上下文
- 读取全部输入图片；若有绘本方案（角色圣经、逐页文案），读 `01-character-style-bible.md`、`02-page-plan.md` 等，确定角色固定外观、场景锚点、每页动作。
- 锁定角色锚点：毛色/衣服/配饰/耳朵/表情基调；场景锚点：固定道具及其位置状态。
- 输入图片就是首帧/参考图，用来锁定角色与场景不漂移。

### 2. 每页规划一个核心微动作
- 每页只给一个主要微动作（放物品/望海/眨眼/风吹），不叠加多动作。
- 微动作要轻柔、幅度小、速度慢；可补 1–2 个环境次动作（海浪、风、海鸥、阳光闪烁）。
- 道具连续性：已放好的物品后续页保持原位、不消失不复制。

### 3. 编译图生视频提示词（每页一条）
统一结构：源图 → 微动作 → 镜头 → 风格 → 音频 → 负面。逐页提示词模板见 `references/micro-motion-guide.md`；完整多页示例见 `references/example-prompts.md`。

通用前置设定（放每条提示词开头）：
```
输入为温暖水彩儿童绘本/插画，轻微纸张纹理，大面积留白，柔和低饱和暖色。
主角：<角色固定外观，从输入图/角色圣经读取>。
场景锚点：<沙滩、野餐布、海、太阳等固定锚点>。
画面全程保持绘本插画质感，不转写实、不转3D、不做大动作，镜头缓慢稳定。
```

音频策略（按此写进每条提示词）：
```
不要背景音乐，不要解说旁白；声音主要由后期剪辑统一加入。允许保留画面内自然音效——物品放置的轻微碰撞声、海浪拍岸、风声、海鸥叫声等环境音可以出现。
```

通用负面提示词（追加在每条提示词末尾）：
```
不要写实照片感，不要3D，不要真人，不要剧烈运动，不要镜头剧烈晃动/快速推拉，不要闪屏，不要文字/字幕乱码，不要画面变形，不要角色表情崩坏，不要多余手、多余耳朵、肢体扭曲，不要水印、logo。
音频：不要背景音乐，不要解说旁白，不要突兀电子音效；物品碰撞、海浪、风声、海鸥叫声等自然音效允许保留（最终声音后期剪辑统一合成）。
```

### 4. 生成视频
- 用 `image_to_video`，输入图作为 `image_reference_url_list` 首帧。
- 参数默认：`ratio` 与源图一致（绘本方形用 `1:1`）；`duration` 微动作 4–6 秒（「让图片动起来」固定 5 秒）；`model_version` 默认 `seedance_2.0_fast`。
- 逐页独立生成；多条可并行，每条独立核对。

### 5. QA 与交付
- 核对：动作是否轻柔且只发生一次、角色/场景锚点是否与源图一致、无多余肢体、画面无文字错乱。
- 保存视频到项目 `videos/` 目录，用 `present_files` 交付。

## 资源
- `references/micro-motion-guide.md`：微动作设计与提示词编译细则。
- `references/example-prompts.md`：一本 8 页绘本的完整逐页提示词示例（含封面），可直接改主体与动作复用。

## 禁止
- 不做写实/3D/真人风格；不做剧烈运镜与闪屏；不叠背景音乐与解说；不无故新增人物、场景或用户没要求的强特效。
