# 微动作设计与提示词编译细则

## 微动作原则
- 每页只一个核心微动作（放物品 / 望海 / 眨眼 / 风吹 / 轻微晃动），幅度小、速度慢。
- 可补 1–2 个环境次动作，不抢戏：海浪缓涌、布角被风吹动、海鸥飞过、阳光闪烁、气泡上浮。
- 一个动作拆到一页，不叠加「拿 + 放 + 看」多动作；低龄绘本宁慢勿满。

## 常见核心微动作（可按主体替换）
- 放物品：双手捧起 → 轻轻放到目标面 → 落稳后松开、微微抬头眨眼。
- 眨眼微笑：轻轻眨眼、嘴角微笑幅度微微变大。
- 望向远方：微微转身/侧头，眼神望向海/天空，耳朵或头发被风吹动。
- 风吹动效：衣摆、野餐布一角、耳朵、草帽被风轻吹起又落下。
- 环境动效：海浪缓缓拍岸、海面波光闪动、海鸥缓缓飞过、阳光柔和闪烁。

## 提示词编译顺序（每条）
1. 源图定位与画幅：`输入为该温暖水彩绘本插画…`
2. 主角与场景锚点：从输入图/角色圣经读取，写固定外观。
3. 微动作：只写本页那一个核心动作 + 环境次动作。
4. 镜头：缓慢稳定；可极轻微推近（约 3%）或极轻微跟随，不晃动。
5. 音频策略：无背景音乐、无解说；允许自然音效（碰撞/海浪/风/海鸥）。
6. 负面词：写实/3D/剧烈运动/镜头晃动/闪屏/文字/变形/多余肢体/水印。

## 参数
- 比例与源图一致（方形绘本用 `1:1`）。
- 时长：微动作 4–6 秒；「让图片动起来」固定 5 秒。
- 模型默认 `seedance_2.0_fast`。
- 输入图作为首帧/参考图锁定角色与场景，避免漂移。
