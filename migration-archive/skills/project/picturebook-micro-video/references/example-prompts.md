# 8 页绘本逐页微动作视频提示词示例

> 示例为一本海边野餐绘本（白兔主角），可直接替换主角外观、场景锚点与动作复用。
> 统一设定：方形 1:1；时长 4–6 秒；保持温暖水彩绘本质感、轻微纸纹、大面积留白；动作轻柔缓慢。
> 输入图为该页插画（首帧/参考图）。

## 通用前置设定（放每条提示词最前）
```
输入插画为温暖水彩儿童绘本，轻微纸张纹理，大面积留白，柔和低饱和暖色。
主角：通体白色软毛、圆润矮胖的卡通小兔，两只长长竖耳朵，粉红鼻头与粉红内耳廓，脸颊淡淡红晕，圆圆黑亮眼睛，穿浅黄色背带裤（白色小纽扣、裤脚卷边）。
场景锚点：浅米色沙滩、红白格野餐布、远处淡蓝海面、浅天蓝天空、右上角暖黄小太阳。
画面全程保持绘本插画质感，不转写实、不转3D、不做大动作，镜头缓慢稳定。
声音：不要背景音乐；声音主要由后期剪辑统一加入。允许保留画面内自然音效——物品放置的轻微碰撞声、海浪拍岸、风声、海鸥叫声等环境音可以出现。
```

## 通用负面提示词（追加在每条末尾）
```
不要写实照片感，不要3D，不要真人，不要剧烈运动，不要镜头剧烈晃动/快速推拉，不要闪屏，不要文字/字幕乱码，不要画面变形，不要角色表情崩坏，不要多余手、多余耳朵、肢体扭曲，不要水印、logo。
音频：不要背景音乐，不要解说旁白，不要突兀电子音效；物品碰撞、海浪、风声、海鸥叫声等自然音效允许保留（最终声音后期剪辑统一合成）。
```

## 封面 · A picnic in the sand
```
基于该绘本插画生成 5 秒视频，方形。小兔站在沙滩野餐布边，双手捧三明治：轻轻眨眼、嘴角微笑幅度微微变大，两手把三明治往上轻轻托一下又放下。阳光在右上角柔和闪烁，红白野餐布一角被海风轻轻吹起又落下。远处海面波光缓缓闪动，一只海鸥在远处缓缓飞过。镜头极缓慢地轻微推近（约 3% 放大），保持水彩绘本质感与大面积留白，动作轻柔缓慢。
```

## 第 2 页 · The sandwich
```

```


## 第 7 页 · We picnic
```
基于该绘本插画生成 6 秒视频，方形。小兔开心地坐在红白野餐布上，微微低头，双手轻轻拿起一块三明治凑到嘴边作享用状（或作满足地眯眼微笑），耳朵轻晃。沙滩上阳光柔和闪烁，远处海浪缓缓拍岸、波光流动，一只海鸥缓缓飞过。野餐布上三明治、汽水、贝壳、海星保持原位。镜头极缓慢推近，回到全场景的温暖收尾感，保持水彩绘本质感。
```

## 使用提示
- 首帧都用对应页插画，角色和场景锚点就不会漂移。
- 页间如需串成完整视频，用淡入淡出或 0.5 秒叠化衔接，节奏慢更像绘本。
- 替换示例时：改主角外观、场景锚点、微动作即可，通用前置设定与负面词保持不变。
