# 分镜设计

只处理用户指定的故事范围。先读相关剧本和已确认资产；不得自行改写故事。项目文件约定见 [../creative-workflow/references/project-format.md](../creative-workflow/references/project-format.md)，分镜字段见 [references/storyboard.schema.json](references/storyboard.schema.json)，报告规则见 [../creative-workflow/references/report-format.md](../creative-workflow/references/report-format.md)。

## 分镜流程

1. 明确场次/段落范围、成片用途、画幅、目标时长、节奏和提示词交付类型；一次列出需要的规格和推荐项。
2. 列故事节拍、镜头组、预计镜头数与时长划分，等待确认后再展开。
3. 按镜头记录叙事目的、景别/角度、构图与空间关系、角色起始状态、可拍摄动作、动作结果、镜头运动、时长、声音提示和连续性锚点。
4. 核对视线/轴线、进出方向、手部和道具状态、人物相对位置、时间与场景变化；一个镜头承载一个清楚的主要动作，动作具有可见起点和结果。
5. 完成后检查每镜是否推进信息、情绪或动作；合并重复镜头，保留必要反应镜头。用“可继续 / 需修改 / 阻断”给出审核结论和带证据的问题。

## 提示词编译

- 将分镜转成可复制的模型无关自然语言提示词，忠于已确认人物、资产、动作和构图；不要把文案描述原样当作视频动作指令。
- 视频提示词为每镜写清初始画面、主体动作过程、镜头运动、环境变化、时长和必须保持的连续性。动作由分镜承担，不另建独立动作 Skill。
- 如用户指定 Seedance 2.0，再将同一提示词适配为该模型可读的段落；不得改变故事内容或暗示已生成视频。
- 用户没有要求生成图片/视频时只输出脚本和提示词，不调用媒体生成工具。

## 文件与报告

分镜清单保存为版本化 JSON，解释性导演备注和审核建议保存为 Markdown；用户需要时生成独立离线 HTML 分镜/提示词报告。报告内所有提示词可完整复制。不得用不存在的媒体文件填充报告。
