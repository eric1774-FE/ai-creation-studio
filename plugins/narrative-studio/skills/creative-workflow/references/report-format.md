# 离线报告约定

- 每个关键阶段独立成一个 HTML 文件，不把故事正文、多个审核阶段和资产清单塞进一个总报告。
- 使用完整自包含 HTML：CSS 内联；不依赖 CDN、远程字体、外部脚本或远程图片。目标是断网可打开、可打印。
- 中文为默认语言。用语短而具体；长提示词应自然换行，不截断正文。
- 审核报告包括结论状态、严重程度、来源证据、影响、原因和可执行建议。资产报告包括 ID、资产类别、确认事实、状态/版本、引用来源和中英提示词。分镜报告包括场次/镜头号、动作、构图/机位、时长、连续性关系和对应提示词。
- 未有图像输出时不要渲染空白图片框；提示词本身需可复制。
- 报告中保留生成日期、项目名和对应资料版本。版本更新时另存新报告，不悄悄覆盖旧交付。
