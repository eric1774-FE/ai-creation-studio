# 绘本创作

覆盖绘本故事到逐页制作资料；用户只要其中一阶段时只完成该阶段。项目文件与报告约定见 [../creative-workflow/references/project-format.md](../creative-workflow/references/project-format.md) 和 [../creative-workflow/references/report-format.md](../creative-workflow/references/report-format.md)。

## 规格与故事

确认受众年龄、主题/阅读目标、页数（是否含封面）、每页文字密度、语言、画幅、情绪与禁忌；一次列出规格和可调整的推荐项。故事先明确主角、愿望、阻碍、变化和结尾，再拆成具有翻页节奏的页面。用户已给完整故事时优先忠于原文，不擅自加说教。

## 分页与视觉一致性

- 每页记录页码、文字、画面主体、动作、场景、构图、留白/文字区域、前后页承接和页面情绪。封面单独规划。
- 建立角色/场景视觉锚点；在资产清单中维护同一项目主风格。没有项目主风格时，在固定角色/场景资产前调用 `asset-design` 的风格确认规则。
- 插画提示词逐页自包含，重复必要的角色身份、服装、场景和风格锚点；不得依赖“同上”。不生成图片。
- 对适龄性、阅读连贯、图文一致、角色状态、道具位置和跨页连续性进行检查，列出需确认或返工页。

## 页面微动作视频提示词

用户要求绘本转视频或页面微动作提示词时，每页设计一个主要轻动作，允许少量环境动作；写明输入静帧职责、动作幅度/起止、镜头、时长、风格保持、音频策略和负面约束。动作服务页面情绪，不改变角色、场景、道具位置和故事结果。默认仅编写提示词，不生成视频。

## 交付

分页、角色/场景设定、插画提示词和页面微动作提示词可分别保存为 Markdown。用户需要时为分页或提示词交付生成独立离线 HTML 报告。
