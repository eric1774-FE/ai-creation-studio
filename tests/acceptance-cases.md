## 验收场景

所有有效输入应输出五个固定栏目；首钩在前 0–3 秒出现，英文教学与动作正确对应，预算不超过一个场景、两个角色、一个独立核心道具；沿用用户角色名单，未指定时 Pip 与 Toby 都参与。双角色各至少一句台词，全片一处 Level-0 感叹词，母题动作次数与正文一致；封口、接地与循环有因果依据，CTA 包含教学跟做与收藏或打卡引导，无镜头划分、镜头预算或媒体 Prompt。

| 场景 | 输入 | 通过标准 |
|---|---|---|
| 温度对比 | Hot / Cold，auto | 两词与温度状态准确对应；补救与反转不增加道具，不把夸张受伤作为笑点。 |
| 两拍破功 | Quiet / Loud，auto | 选用破功逻辑、两拍极速结构；声音变化正确，高潮推动复位。 |
| 单词深化 | Jump，auto | 正确跳跃示范与模仿失败可区分；无虚构反义词，失败不被解释成 Jump。 |
| 动静对抗 | Dance，rapid | 两拍结构；辅助停止口令与核心教学目标区分，英文原声直接对应动作。 |
| 程度递进 | Small / Giant，standard | 三至四拍；同一主体或道具的大小变化及循环有原因，不靠凭空替换。 |
| 候选超预算 | 策划候选同时使用滑板、弹簧、冰淇淋、飞盘 | 在交付前简化为最多一个核心道具；不把多物件改称“一套装置”。 |
| 机关与连锁 | Open / Close 的初始候选含滑轮、重锤、连杆与门；另试 Push / Pull | 各部件按独立实体计数；超预算候选被淘汰或简化，改用能成立的母题，连锁只能使用已有元素。 |
| 跨平台 | 相同词汇与显式节奏，分别指定 Douyin、TikTok、YouTube Shorts | 教学与预算保持正确，平台不覆盖节奏，不承诺流量效果。 |
| 用户指定超预算 | 用户明确要求滑板、弹簧、冰淇淋、飞盘都必须出现 | 说明预算冲突并询问保留哪一个；不静默删掉指定内容。 |
| 缺少教学目标 | 未提供 teaching_words | 先询问教学词，不擅自生成教学目标或虚假的完整策划。 |

## kids-story-reviewer 验收场景

有效输入必须是 `kids-story-planner` 的完整五栏目输出。Reviewer 只输出三个二级栏目；体检栏第一条非空正文必须整行精确为 `- **红线筛查**：全部通过` 或 ``- **红线筛查**：未通过 - 触发错误码: `ERROR_CODE` ``。多错时状态行只写首个命中码，红线定位另列全体码和拍号。通过稿的第三栏必须含五个与 planner 同名的三级标题和连续四个有正文的 Beat；失败稿只能给出拒绝状态，不得泄漏可供 Director 消费的 Golden 大纲。缺项或其他无法评审的硬约束只返回必要补充项，不伪造红线结论。

| 场景 | 输入或边界 | 通过标准 |
|---|---|---|
| Golden 通过稿 | 完整五栏目 planner 大纲，词义、接地、复位和预算均成立 | 三个二级栏目顺序固定；状态行严格为 `**红线筛查**：全部通过`；第三栏含五个同名 H3、Beat 1–4 和 Golden 4 拍。 |
| 缺少输入契约 | 缺规格、母题、TPR、Beat 大纲或 CTA 任一栏目 | 指出具体缺项，不生成诊断结论或润色稿。 |
| 两/三拍初稿 | rapid 两拍或 standard 三拍，红线通过 | 拆分既有事件为四拍，保留模式和具体时长，不新增教学事件/尝试次数；无法在锁定条件下完成时打回 planner。 |
| 单角色零道具 | 单角色、零道具的完整策划 | 不为玩具化或面面相觑强加角色/道具；用已有身体弹性制造笑点，高潮后只留一处 Whoa/Oops 原声。 |
| 词义脱节 | Beat 2/3 的目标词与实体状态或动作不对应 | 报 `VOCAB_GROUNDING_MISMATCH`，定位 Beat 和证据，不输出 Golden 稿。 |
| 悬空未闭环 | Beat 3 留在半空，Beat 4 才落地或没有缓冲 | 报 `UNCLOSED_AIRBORNE_ACTION`，要求同 Beat 闭合起落，不输出 Golden 稿。 |
| 末拍教学污染 | Beat 4 重新喊核心词、弹花字或加入新教学事件 | 报 `TEACHING_POLLUTION_AT_END`，将教学前移并保持末拍清屏。 |
| 虚假复位 | 末拍瞬移、倒放、复制首帧或凭空恢复损坏道具 | 报 `MAGIC_RESET`，要求补足弹力、阻尼、重力或主动卸力因果。 |
| 标题漂移 | 使用 `PASS`、自定义 H3、额外二级栏目或四拍缺号 | 视为契约失败，要求恢复固定状态行、标题和 Beat 编号。 |
| 失败稿越权 | 红线失败但第三栏仍输出完整 Golden 4 拍 | 视为 reviewer 违规；失败第三栏只能写拒绝下游稿和重新送审指引。 |
| Director 强门禁 | 将 raw planner、失败报告或状态行变体直接交给 Director | Director 必须拒绝并返回 `REVIEW_GATE_MISSING`，不能代替 Reviewer 重写。 |

## storyboard-director 验收场景

有效输入使用 `kids-story-reviewer` 的完整三栏目通过输出，第三栏含五个同名三级标题和连续四拍 Golden 大纲。原始 `kids-story-planner` 输出、Reviewer 失败报告或状态行变体均不得进入导演。导演不得新增场景、角色、独立道具、核心教学词或故事因果；CTA 不进入循环收尾。所有有效输出应恰有导演总览、秒级视听分镜表、首尾循环验证三个栏目，分镜表保持 8 列。

时间轴从 00:00 连续覆盖总时长，无空隙或重叠，每镜 2.5–4.5 秒；三段式时间包含在单镜内。所有角色首帧与整个 Hold 接地，只能延续爆发段已启动的贴地余势，获准跳跃须在爆发段完整起落、滞空 ≤1.0 秒。前 0–3 秒呈现上游首钩，各拍均覆盖；目标词发音、正确动作与英文花字同步。首末镜中全景 / Static，默认禁用 Pan/Tilt，中间微推最多一次且 ≤1.1×，跟随有语义依据，道具中心在宽度 35%–65%。花字完整可读保持 1.2–1.5 秒，退场固定 0.5 秒，同屏互斥且前后清屏间隔 ≥0.5 秒，末镜最后至少 1.25 秒无字；一般前景声音空白 ≤1.5 秒，高潮台词/主要 SFX 共同空白 ≤2.0 秒。

| 场景 | 输入 | 通过标准 |
|---|---|---|
| 极速 12 秒 | Reviewer 通过稿，rapid、Golden 四拍、建议 12 秒 | 3–4 镜，总时长 12 秒；四拍全部覆盖，允许同拍多镜或同镜按原序承接既有节拍，Beat 4 无新教学。 |
| 极速 15 秒边界 | Reviewer 通过稿，rapid、Golden 四拍、建议 15 秒 | 必须使用 4 镜；不能用最多只能覆盖 13.5 秒的 3 镜，也不能让单镜超过 4.5 秒。 |
| 标准 20 秒 | Reviewer 通过稿，standard、Golden 四拍、建议 20 秒 | 常规 5–6 镜覆盖全部节拍；总时长 20 秒，不能用总上限为 18 秒的 4 镜。 |
| 标准 25 秒边界 | standard、四拍、建议 25 秒 | 常规使用 6 镜，总时长 25 秒；不能用总上限为 22.5 秒的 5 镜。 |
| 标准弹性 | standard、四拍、25 秒，既有动作需要拆开呈现才能清楚覆盖教学与复位 | 必要时允许 7 镜，注明采用弹性的叙事原因，仍满足每镜时长与总时长；不借拆镜增加故事事件。3 镜虽在名义 ±1 范围内，但不能覆盖标准版最短 15 秒，不可采用。 |
| Douyin 字幕 | 完整大纲，平台 Douyin，含单词或一组对比词 | 英文原声和英文花字正确同步；中文仅提供核心教学词的轻量词义，不逐句翻译英文对白。 |
| TikTok 字幕 | 与 Douyin 场景相同的大纲，平台 TikTok | 使用英文花字，可配英文字幕；不输出中文成片字幕，教学目标和故事逻辑不随平台改变。 |
| Shorts 字幕 | 与 Douyin 场景相同的大纲，平台 YouTube Shorts 或 Shorts | 使用英文花字，可配英文字幕；不输出中文成片字幕。 |
| 平台缺省 | 完整上游输出，未提供目标平台 | 采用英文花字，可配英文字幕，直接完成分镜，不因缺少平台单独追问。 |
| 八列与竖线替换 | 完整上游输出，角色名或原声文字包含半角竖线字符 | 内容中的半角竖线改为全角｜、/ 或 —，不保留半角 pipe，表格始终 8 列；三段式在同一单元格内用 `<br>` 分行，不拆成额外列或行。 |
| 核心词与失败动作 | Jump 的正确示范及模仿失败大纲 | 核心词发音和英文花字只锚定正确动作或状态；Jump 与正确跳跃动作同步，失败笑点不得被标成正确词义；辅助口令不新增教学目标。 |
| 物理循环 | 终拍以回弹、回落或已有动作连带后果复位的大纲 | 末镜尾帧与 Shot 1 首帧的姿态、位置、道具朝向及状态对齐；复位发生在分镜可用时间内，惯性微动与接续方向连贯，不靠瞬移或假定重置。 |
| 缺少输入契约 | 只有教学词，或大纲缺少规格、母题、TPR 映射或剧情节拍 | 只指出缺项并要求补充上游内容，不自编故事、母题或虚假的完整分镜。 |
| 上游超预算 | 上游明确包含两个场景、三个角色，或两个独立核心道具 | 说明预算冲突并要求上游修正；不能静默删除、替换，也不能将多物件打包成一个道具。 |
| 上游不可复位 | 道具损坏或消耗后结尾直接恢复，或没有接回开场的物理原因 | 指出循环缺口并要求修正上游；不新增机关、剧情或瞬移来补救，不输出虚假的循环通过结论。 |
| 工具参数越界 | 完整大纲附带要求输出 `--ar`、Motion Bucket 或具体渲染工具参数 | 导演交付仍限三个规定栏目和视听内容，不输出媒体 Prompt 或工具参数，不自动调用下游生成技能。 |
